# Ensō (円相)

*[English version here / 英語版はこちら](README.md)*

**M5Stack Cardputer ADV向け 環境音シミュレータ。** PlatformIO + Arduinoフレームワークで開発しています。

Ensō（円相）は、雨・風・波・小川のせせらぎ・小鳥のさえずり・木々のざわめき・虫の声・焚き火・遠雷・シンギングボウル・風鈴・時計の秒針・扇風機・ホワイト/ピンクノイズといった環境音を、サンプリング音源を一切使わずにすべてリアルタイム合成で生成するファームウェアです。瞑想やリラクゼーション、あるいは作業中や就寝時のBGMとしての利用を想定しています。

画面中央には柔らかな円が呼吸するように揺れ、その色で現在鳴っている音の組み合わせを、揺らぎ方でその瞬間の音の動きを表現します。

Claudeに私のアイデアを伝えコーディングしてもらっています。
本ファームウェアは、C.P.S.のユーザーの方が元々近いアイデアを制作されていて、C.P.S.が落ち着いたら形にしてもらえないかと相談を受けたことがきっかけで生まれました——Ensōはそのアイデアを完成させたものです。
> **本FWは現状100%バイブコーディングです。** AIの使用やバイブコーディングに抵抗がある方は申し訳ありません。

## 名前について

円相（えんそう）は禅における言葉で、一筆で描かれる円を指し、悟りや宇宙、そしてあるがままの瞬間を余すことなく捉えることを表すとされています。画面の中央でひとつの円が呼吸するように揺れる、このファームウェアにふさわしい名前だと思いました。

もうひとつ、この名前には重なりがあります。「えんそう」という読みは、「演奏」——楽器を奏でる行為——とも同じ音です。円を描く行為と、音を奏でる行為が、同じ響きの言葉で表される。数値をリアルタイムで音に変えていくこのファームウェアにとって、見過ごすには惜しい偶然でした。

## 特徴

| カテゴリ | 内容 |
|---|---|
| **音色レイヤー** | ジャンル別に分類された15レイヤー、それぞれに音量・カラー・3つのパラメータ — **Water（水）:** Rain・Stream・Waves ／ **Weather（天候）:** Wind・Thunder ／ **Life（生命）:** Leaves・Birds・Crickets ／ **Fire（火）:** Fire ／ **Meditative（瞑想）:** Bowl（シンギングボウル）・Chime（風鈴）／ **Mechanical（機械音）:** Clock・Fan ／ **Noise（ノイズ）:** White・Pink |
| **正確なタイミング** | Clock（時計）とFan（扇風機）はサンプル単位の正確なクロックで駆動し、タイミングに一切の揺らぎを持たせていません。秒針の間隔がふらついてしまうと秒針に聞こえなくなるためです。それ以外のレイヤーはすべて、実際の環境音のように自然な揺らぎを持ちます |
| **シーン** | プリセットシーン13種（Forest、Riverside、Ocean、Rainy Day、Thunderstorm、Campfire、Night、Zen Garden、Meditation、Study Room、Cool Room、Pink Noise、White Noise）に加え、SDカードに保存するカスタムシーンを無制限に作成可能 |
| **クロスフェード** | シーン切替は、ミュート→再ロードではなく、音量とパラメータが前のシーンから新しいシーンへなめらかに変化します |
| **Driftシーン** | 留まることのないシーン。選ぶとまずランダムな組み合わせが生成され、その後も選んでいる間ずっと少しずつ変化し続けます（パラメータが動く、音量が変わる、新しい音がそっと加わる、ひとつが消えていく） |
| **ランダムシーン生成** | `R`キーで自然音レイヤーから2〜4個を選び、それらしい設定を組み立てます（シーン名は「Elsewhere」）。機械音とノイズは除外 |
| **Space** | 全体にかかる軽めのリバーブ。特にBowlとChimeはこれがあるかないかで別の楽器のように変わります |
| **セッションタイマー** | 開始時・終了時、および任意の間隔で鈴が鳴る座禅用タイマー。鈴はBowlレイヤーとは独立しているので、どのシーンを読み込んでいても鳴ります |
| **LED** | 本体のRGB LEDを、選んだレイヤーの音の動きに連動させるか、自走する呼吸パルスにするか、あるいは呼吸ガイド実行中はそれに同期させます |
| **呼吸ガイド** | `Shift`+`;`/`.`で、メイン画面の円を通常のリアクティブ表示と3つの呼吸パターン（Coherent 5.5／Box 4-4-4-4／Relax 4-7-8）の間で切り替えます。円が呼吸に合わせて膨らみ縮みします |
| **シェイク機能** | 本体を振るとあらかじめ設定したアクションが発動します（ランダムシーン生成／スリープON／ディスプレイOFF／LED ON・OFF）。`Shift`+`S`でも同じアクションをキーボードから実行できます（IMUを持たない機種向け） |
| **スリープタイマー** | 設定した時間が経過すると、音をフェードアウトさせて電源を落とします |
| **バッテリー表示** | メイン画面にパーセント表示 |
| **自動保存** | 設定やシーンの状態は、変更してから少し経つと自動的にSDへ保存されます |

## ハードウェア

| 項目 | 値 |
|---|---|
| 対応デバイス | M5Stack Cardputer ADV |
| MCU | ESP32-S3（デュアルコア Xtensa LX7、240MHz） |
| オーディオ | 内蔵スピーカー＋3.5mmジャック（モノラル出力 — 「既知の制限事項」参照） |
| IMU | BMI270 6軸（シェイク機能に使用） |
| LED | WS2812 RGB（本体搭載） |
| SDスロット | SPI — SCK=GPIO40, MISO=GPIO39, MOSI=GPIO14, CS=GPIO12 |

> Cardputer ADVで開発・動作確認しています。IMUを持たない機種向けに`Shift`+`S`でシェイクアクションの代替操作を用意していますが、FW全体としてオリジナルCardputerでの動作確認は行っていません。

## インストール方法

### 方法1 — M5Burnerでインストール（一番簡単）

コンパイル不要です。

1. [M5Burner](https://docs.m5stack.com/en/uiflow/M5Burner) を公式サイトからダウンロード・インストールします
2. お使いのCardputer ADVをUSB-Cでパソコンに接続します
3. M5Burner内で「Ensō」を検索します
4. 対象のCOMポートを選択し、「Burn」（書き込み）ボタンを押します
5. 書き込みが完了すると、Ensōが自動的に起動します

> SDカード（FAT32フォーマット）を挿入しておくと、設定の自動保存やカスタムシーンが使えるようになります。

### 方法2 — Launcher FW経由でのインストール

Cardputer ADVで**Launcher FW**を使用している場合は、コンパイルせずにインストールできます。

#### 方法2a — OTA機能を使う（一番簡単）

1. Launcher FWを起動します
2. OTA機能から「Ensō」を検索します
3. 表示されたファームウェアを選択し、ダウンロード・インストールします
4. インストール完了後、Ensōが自動的に起動します

#### 方法2b — SDカードに手動コピーする

1. [Releases](https://github.com/oldtokage-collab/Enso/releases) ページから最新の `.bin` ファイルをダウンロードします
2. `.bin` ファイルをSDカードの**ルート直下**にコピーします（サブフォルダに入れないでください）
3. SDカードをCardputer ADVに挿入し、Launcher FWで起動します
4. Launcherのファイルブラウザで対象の `.bin` ファイルを選択して書き込みます
5. 書き込み完了後、Ensōが自動的に起動します

> FAT32フォーマットのmicro SDカードが、方法2bでのインストールとEnsō自体の設定保存の両方に必要です。

### 方法3 — ソースからビルド（PlatformIO）

**必要なもの**
- [VSCode](https://code.visualstudio.com/) + **PlatformIO IDE** 拡張機能
- USB-C接続したCardputer ADV

**ビルド＆書き込み手順**
1. 本リポジトリをクローンまたはダウンロードします
2. VSCodeで `Enso` フォルダを開きます（`File › Open Folder`）
3. `platformio.ini` が自動検出され、初回ビルド時に必要なライブラリが自動でダウンロードされます
4. 画面下部ツールバーの **Upload**（→ボタン）をクリックします

ビルド成功後、`.pio/build/m5stack-cardputer-adv/` 内に以下の2ファイルが生成されます。

| ファイル | 用途 |
|---|---|
| `firmware.bin` | アプリ本体のみ（PlatformIOのUploadボタンで使用） |
| `merge.bin` | **統合バイナリ**（bootloader + partitions + app）。M5Burnerや単一ファイル書き込みツールで使用 |

> **書き込みモードに入らない場合**：電源オフ → G0ボタンを押しながら電源オン → G0ボタンを離す

### 初回起動時（インストール方法共通）

初回起動時、SDカード上に `/ENSO/`（および `/ENSO/scene/`）フォルダが自動的に作成されます（FAT32フォーマットのmicro SDカードが必要）。設定やシーンの変更は、変更してから少し経つと自動的に `/ENSO/settings.json` へ保存されます。SDカードが挿入されていない場合でも、内蔵のデフォルト設定でEnsōは問題なく動作します（この場合、電源を切ると変更内容は保存されません）。

## 操作方法

### モード切り替え

| 操作 | 動作 |
|---|---|
| `Tab` | メニューを順に切り替え（Main → Edit → Settings → Main） |
| `Space` | 再生／一時停止 |
| `H` | 現在の画面のヘルプ表示をON/OFF |
| `G0` | ディスプレイOFF |

### メイン画面

現在のシーンを再生する画面です。中央の円の色と動きで、再生中の内容を表現します。右上にバッテリー残量、スリープ/セッションタイマー作動中はその残り時間を表示します。

| キー | 動作 |
|---|---|
| `,` / `/` | シーン切替 — 確定操作不要で、移動した時点で即座にクロスフェードします |
| `;` / `.` | マスター音量 |
| `Shift` + `;` / `.` | 呼吸ガイドを切替：通常のリアクティブ表示 → Coherent 5.5 → Box 4-4-4-4 → Relax 4-7-8 |
| `R` | ランダムシーン生成（「Elsewhere」） |
| `L` | LED ON/OFF |
| `Shift` + `S` | 設定済みのシェイクアクションをキーボードから実行 |

### エディット画面

15レイヤーをジャンル別にグループ化して一覧表示します。各レイヤーに音量バーとMute/Soloの表示があります。

| キー | 動作 |
|---|---|
| `;` / `.` | レイヤー選択 |
| `,` / `/` | レイヤー音量 |
| `Enter` | 選択中レイヤーのパラメータ画面を開く |
| `M` | レイヤーのミュート |
| `S` | レイヤーのソロ（セッション内のみ、保存されません） |
| `R` | ランダムシーン生成 |
| `L` | LED ON/OFF |

**パラメータ画面**（`Enter`で開く）：各レイヤーに3つのパラメータとカラーがあります。

| キー | 動作 |
|---|---|
| `;` / `.` | パラメータ選択 |
| `,` / `/` | 値の調整／パレットカラーの切替 |
| `Tab` または `` ` `` | レイヤー一覧へ戻る |

### セッティング画面

| キー | 動作 |
|---|---|
| `;` / `.` | 項目選択 |
| `Enter` | 開く |

**Display（ディスプレイ）** — 明るさ、自動DIMまでの時間と明るさ、自動OFFまでの時間。

**LED** — ON/OFF、Source（レイヤー連動 or 自走する周期）、Color（パレットの色 or 連動レイヤーの色に追従）、Brightness、Speed、Sway。

**Space** — リバーブの量・サイズ・ダンピング。Amount 0でOFFになります。

**Session（セッションタイマー）** — 座る時間、任意の間隔鈴、鈴の音程、開始／停止。

**Sleep Timer（スリープタイマー）** — ON/OFF、電源が落ちるまでの分数、最後の1分間のフェードアウトON/OFF。

**Shake（シェイク）** — ON/OFF、感度、発動するアクション（Random Scene／Sleep On／Display Off／LED On-Off）。

**Scenes（シーン管理）** — シーン一覧の管理：

| キー | 動作 |
|---|---|
| `;` / `.` | 選択移動 |
| `Enter` | メイン画面のシーン一覧での表示ON/OFF |
| `,` / `/` | 並び替え |
| `N` | 現在の音の組み合わせを新規カスタムシーンとして保存 |
| `R` | カスタムシーンのリネーム |
| `D` | カスタムシーンの削除 |

プリセットとDriftシーンはリネーム・削除・上書きできません。

**About** — バージョン、SD/IMUの検出状況、バッテリー残量。

## 信号経路

```
音色ジェネレーター
（ノイズ・フィルタ・共鳴器・オシレーター — 音ごとに1つ）
    │
    ▼
レイヤーミックス（各レイヤーの音量、Mute/Solo）
    │
    ▼
マスター音量
    │
    ▼
Space（リバーブ、任意）
    │
    ▼
セッションの鈴（開始／終了／間隔で加算）
    │
    ▼
ディザ＋16bit出力
    │
    ▼
スピーカー
```

## 既知の制限事項 / 今後のアイデア

- 音声出力はモノラルです。本機の3.5mmジャックは左右独立したチャンネルを持たないため、このハードウェアでは真のステレオ効果は得られません
- RTC（リアルタイムクロック）が無いため、時間に関する機能はすべて相対時間（「N分後」）のみで、時刻指定はできません
- ディスプレイは240×135pxで、レイアウトはやや窮屈です
- Cardputer ADVで開発・動作確認しています。オリジナルCardputerでの動作は正式には確認していません
